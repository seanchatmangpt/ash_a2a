\begin{abstract}
As autonomous artificial agents scale toward Artificial General Intelligence (AGI), their interactions transcend naive remote procedure call paradigms. Agent interaction requires a formal calculus of agency, verification, and authority. This dissertation establishes a rigorous, unified mathematical and empirical foundation for the Agent-to-Agent (A2A) Protocol Specification v1.0, its comprehensive testing lifecycle, and its reference implementation in \texttt{ash\_a2a}.

We formalize machine agency via the \textbf{Chatman Equation}:
\[
\mathcal{A} = \mu(\mathcal{O}^*), \quad \mathcal{R} = \mathrm{receipt}(\mathcal{A})
\]
where raw observation $\mathcal{O}$ is filtered through an adversarial admission operator to yield grounded reality $\mathcal{O}^*$, lawful manufacture $\mu$ executes deterministic actuation $\mathcal{A}$, and execution standing is strictly derived from a cryptographic 5-tuple receipt $\mathcal{R}$. 

We develop the algebraic and category-theoretic foundations of agent messaging through symmetric monoidal categories $\CatAgent$, sheaf cohomology over distributed task graphs, and principal fiber bundles where authority narrowing satisfies $C_{\mathrm{child}} \subseteq C_{\mathrm{parent}}$. We further formulate the infinitesimal calculus and dynamical systems model of autonomous recursion, establishing Lyapunov stability criteria that guarantee self-stabilizing execution $\frac{dW}{dt} \le 0$ without human intervention.

Finally, we analyze the tripartite wire transport manifold (isomorphic mapping across JSON-RPC 2.0, HTTP+JSON/REST, and gRPC/HTTP-2), and detail the execution of the Technology Compatibility Kit (TCK), proving 100\% conformance across 265 rigorous verification scenarios. We present the concrete implementation architecture of \texttt{ash\_a2a}, incorporating Spark DSL metaprogramming, BEAM process supervision, multi-shard EKV consensus, SPIFFE mTLS zero-trust identity, AuthZEN authorization, CMEK envelope encryption, and post-quantum ML-DSA-65 WASM Affidavit attestation.
\end{abstract}

\section{The Epistemic Gap: Observation versus Grounded Reality}
In distributed multi-agent systems operating under unbounded uncertainty, classical assumptions of shared memory and trusted execution fail. An autonomous agent receives external stimuli comprising telemetry, user instructions, peer messages, and tool outputs.

\begin{definition}[Raw Observation Space]
Let $\mathcal{O}$ denote the space of raw observations. An element $o \in \mathcal{O}$ consists of unvalidated, noisy, or adversarial tokens, strings, and propositions generated by environmental actors or stochastic large language models.
\end{definition}

Raw observations cannot serve as the input to irreversible actuation. To allow actuation on $\mathcal{O}$ directly is to commit an epistemic type error:
\[
\mu(\mathcal{O}) \implies \text{\textbf{Unlawful Actuation (Type Error)}}.
\]

\begin{definition}[Admitted Ground Truth]
Let $\mathcal{O}^* \subset \mathcal{O}$ denote the admitted reality subspace defined by the admission projection $\pi_{\mathrm{admit}}: \mathcal{O} \to \mathcal{O}^* \cup \{\bot\}$:
\[
\mathcal{O}^* = \mathcal{O} \cap \mathbf{Grounded}(\mathrm{SHA}) \cap \mathbf{Bounded} \cap \mathbf{Admitted}(\mathbf{Gate})
\]
where $\mathbf{Grounded}(\mathrm{SHA})$ requires cryptographic provenance down to exact source commits and hardware receipts, $\mathbf{Bounded}$ enforces semantic authority ceilings, and $\mathbf{Admitted}$ represents an adversarial predicate capable of, and witnessing, typed refusal.
\end{definition}

\begin{axiom}[The Law of Anti-Vacuity]
A verification gate $G: \mathcal{X} \to \{\mathrm{Pass}, \mathrm{Fail}\}$ carries non-zero information bits if and only if there exists an admitted witness mutation $x' \in \mathcal{X}$ such that $G(x') = \mathrm{Fail}$. A gate that cannot refuse is vacuous ($\mathcal{O}^* \equiv \mathcal{O}$), destroying the safety bounds of the system.
\end{axiom}

\section{Lawful Manufacture and Cryptographic Receipts}

\begin{definition}[The Chatman Formulation]
Given admitted state $\mathcal{O}^*$, lawful manufacture is a deterministic morphism $\mu: \mathcal{O}^* \to \mathcal{A}$ mapping grounded reality to admissible actuation:
\begin{equation}
\mathcal{A} = \mu(\mathcal{O}^*)
\end{equation}
Every actuation $\mathcal{A}$ emits a non-forgeable proof-of-execution called a \textbf{Receipt}:
\begin{equation}
\mathcal{R} = \mathrm{receipt}(\mathcal{A}) = \langle \mathrm{identity}, \mathrm{authority}, \mathrm{consequence}, \mathrm{replay}, \mathrm{standing} \rangle
\end{equation}
\end{definition}

The fields of the receipt 5-tuple are formally bounded:
\begin{enumerate}
    \item \textbf{Identity}: Cryptographic binding to the exact subject artifact (SHA-256 / BLAKE3), compiler version, and environment.
    \item \textbf{Authority}: The formal lease, delegation token, or SPIFFE SVID granting permission for this exact actuation.
    \item \textbf{Consequence}: The durable ledger mutation, state delta, or event log produced by $\mathcal{A}$.
    \item \textbf{Replay}: Byte-identical reproduction instructions verifying that re-execution of $\mu(\mathcal{O}^*)$ under identical parameters yields identical consequences.
    \item \textbf{Standing}: The derived lifecycle status computed dynamically by an adversarial court ($\mathrm{ALIVE}$, $\mathrm{REFUSED}$, $\mathrm{BLOCKED}$, or $\mathrm{UNKNOWN}$), never asserted literally by the subject itself.
\end{enumerate}

\section{The Symmetric Monoidal Category $\CatAgent$}
We model concurrent agent communication networks within category theory.

\begin{definition}[Category of Agents]
Let $\CatAgent$ be a symmetric monoidal category $(\CatAgent, \otimes, I, \alpha, \lambda, \rho, \gamma)$ where:
\begin{itemize}
    \item \textbf{Objects}: Agent interfaces $A, B, C \in \mathrm{Ob}(\CatAgent)$, defined by their schema contracts, supported input/output modes, and capability declarations.
    \item \textbf{Morphisms}: Asynchronous message transformations and task invocations $f: A \to B$, representing lawful transitions from client intent to agent task execution.
    \item \textbf{Monoidal Product}: Parallel composition $A \otimes B$, denoting concurrent, non-interfering agent interactions.
    \item \textbf{Monoidal Unit}: The idle or null agent $I$.
\end{itemize}
\end{definition}

\begin{theorem}[Associativity and Coherence of Agent Streams]
The Mac Lane coherence theorem applies to $\CatAgent$: all formal diagrams constructed from the associator $\alpha_{A,B,C}: (A \otimes B) \otimes C \xrightarrow{\sim} A \otimes (B \otimes C)$ and unitors commute, guaranteeing that multi-agent stream composition order does not induce topological divergence.
\end{theorem}

\section{Sheaf Cohomology on Distributed Task Spaces}
Let $X$ be a topological space whose points represent distributed task states. We assign to each open set $U \subset X$ the algebra of local observations $\mathcal{F}(U)$.

\begin{definition}[Task Observation Sheaf]
A presheaf $\mathcal{F}$ of state records is a sheaf if for every open cover $\{U_i\}_{i \in I}$ of $U$, given compatible sections $s_i \in \mathcal{F}(U_i)$ such that
\[
s_i|_{U_i \cap U_j} = s_j|_{U_i \cap U_j} \quad \forall i, j \in I,
\]
there exists a unique global state section $s \in \mathcal{F}(U)$ with $s|_{U_i} = s_i$.
\end{definition}

\begin{proposition}[Semantic Inconsistency as Cohomological Obstruction]
In an adversarial or partially partitioned agent network, inconsistencies between distributed node logs represent non-trivial elements in the first cohomology group:
\[
[\omega] \in H^1(X, \mathcal{F})
\]
A task achieves terminal consensus if and only if its obstruction class vanishes: $H^1(X, \mathcal{F}) = 0$.
\end{proposition}

\begin{theorem}[Monotonic Capability Narrowing]

C_{\mathrm{child}} \subseteq C_{\mathrm{parent}}

\end{theorem}

\section{Continuous-Time Autonomic Recursion}
The evolution of an autonomous software ecosystem can be characterized in continuous time by treating the accumulation and resolution of work orders as a dynamical system.

\begin{definition}[Work Order Debt Function]
Let $W(t) \in \Rspace_{\ge 0}$ denote the total unmerged candidate debt across the agent fleet at time $t$. Let $\lambda(t)$ be the rate of candidate construction (generation rate by agents), and let $\mu(t)$ be the rate of lawful cryptographic admission:
\begin{equation}
\frac{dW}{dt} = \lambda(t) - \mu(t)
\end{equation}
\end{definition}

\begin{theorem}[Autonomous Stability Criterion]
A multi-agent development factory is autonomic and stable if and only if there exists an invariant window $\Delta t$ such that without human intervention:
\begin{equation}
\frac{dW}{dt} \le 0 \quad \iff \quad \mu(t) \ge \lambda(t)
\end{equation}
If $\lambda(t) > \mu(t)$, the system diverges into an epistemic debt crisis, where unverified hallucinated PRs and stale work trees overwhelm verification bandwidth.
\end{theorem}

\begin{proof}
Consider the Lyapunov candidate function $V(W) = \frac{1}{2} W(t)^2$. Its time derivative along the trajectories of the system is:
\[
\dot{V}(W) = W(t) \frac{dW}{dt} = W(t) (\lambda(t) - \mu(t))
\]
Since $W(t) \ge 0$, $\dot{V}(W) \le 0$ holds if and only if $\lambda(t) \le \mu(t)$. By Lyapunov's direct method, $W(t) = 0$ is an asymptotically stable equilibrium if $\mu(t) > \lambda(t)$ whenever $W(t) > 0$.
\end{proof}

\]
A protocol court triggers automated isolation and process kill when $\|S_m\|$ breaches the control limit $h$.

\section{The Tripartite Isomorphism}
The Agent-to-Agent (A2A) v1.0 protocol defines three standardized transport bindings. Rather than viewing them as disjoint protocols, we prove they form an isomorphic manifold over the abstract A2A protocol schema $\mathcal{S}_{\mathrm{A2A}}$.

\begin{definition}[Tripartite Transport Projections]
Let $\mathcal{M}$ be the abstract protocol message space. There exist invertible bi-directional encoders:
\begin{align*}
\phi_{\mathrm{RPC}} &: \mathcal{M} \xrightarrow{\sim} \text{JSON-RPC 2.0 (TCP/HTTP)} \\
\phi_{\mathrm{REST}} &: \mathcal{M} \xrightarrow{\sim} \text{HTTP+JSON (OpenAPI / REST)} \\
\phi_{\mathrm{gRPC}} &: \mathcal{M} \xrightarrow{\sim} \text{gRPC over HTTP/2 (Protobuf v3)}
\end{align*}
satisfying the commuting diagram:
\begin{equation}
\begin{tikzcd}
& \mathcal{M} \arrow[dl, "\phi_{\mathrm{RPC}}"', swap] \arrow[d, "\phi_{\mathrm{REST}}"] \arrow[dr, "\phi_{\mathrm{gRPC}}"] & \\
\text{JSON-RPC} \arrow[r, "\psi_{1}"] & \text{REST} \arrow[r, "\psi_{2}"] & \text{gRPC}

\end{equation}
where $\psi_1 = \phi_{\mathrm{REST}} \circ \phi_{\mathrm{RPC}}^{-1}$ and $\psi_2 = \phi_{\mathrm{gRPC}} \circ \phi_{\mathrm{REST}}^{-1}$ are canonical isomorphisms.

\section{Streaming Backpressure and Multiplexing Isolation}
In gRPC and Server-Sent Events (SSE), concurrent subscribers must receive independent event pumps.

\begin{theorem}[Stream Isolation Invariant]
Let $S_1, S_2$ be two independent streams subscribed to task $T$. If subscriber $S_1$ cancels its HTTP/2 stream (sending \texttt{RST\_STREAM}), the pump for $S_2$ must remain active, preserving event sequence monotonicity:
\[
\mathrm{seq}(e_{k+1}) > \mathrm{seq}(e_k) \quad \forall e \in S_2.
\]
Furthermore, on initial subscription via \texttt{SubscribeToTask}, the stream must yield the snapshot $T_0 = \mathrm{TaskSnapshot}$ as sequence 0 before streaming subsequent delta events.
\end{theorem}

\section{The Technology Compatibility Kit (TCK) as Bisimulation}
Protocol conformance cannot be established by informal unit testing. It requires bisimulation between the official Google/Linux Foundation Technology Compatibility Kit automaton $\mathcal{M}_{\mathrm{spec}}$ and the System Under Test (SUT) automaton $\mathcal{M}_{\mathrm{sut}}$.

\begin{definition}[Protocol Bisimulation]
A binary relation $R \subseteq Q_{\mathrm{spec}} \times Q_{\mathrm{sut}}$ is a strong protocol bisimulation if for every $(p, q) \in R$ and input stimulus $a \in \Sigma$:
\begin{enumerate}
    \item Whenever $p \xrightarrow{a} p'$, there exists $q'$ such that $q \xrightarrow{a} q'$ and $(p', q') \in R$.
    \item Whenever $q \xrightarrow{a} q'$, there exists $p'$ such that $p \xrightarrow{a} p'$ and $(p', q') \in R$.
    \item Wire responses (headers, status codes, JSON/Protobuf payloads) are byte-equivalent modulo dynamic timestamp and nonces.
\end{enumerate}
\end{definition}

\section{Anatomy of Critical Protocol Boundary Resolutions}
During the convergence to zero TCK failures, several subtle protocol corner-cases were resolved:
\begin{enumerate}
    \item \textbf{STREAM-ORDER-004 (gRPC Multi-Stream Ordering)}: In \texttt{server.ex}, the lazy enumerator \texttt{stream\_enum/3} initially filtered out events of kind \texttt{"task"}. However, \texttt{SubscribeToTask} requires emitting the current Task snapshot as the very first stream response. Removing this artificial filter allowed parallel stream clients to immediately receive the baseline state without timing out.
    \item \textbf{Protobuf Default String Serialization}: The Protobuf JSON mapping spec requires strings to map to \texttt{""} rather than being omitted when bound to non-optional proto fields. In \texttt{AshA2A.Protocol.JSON}, events \texttt{StatusUpdate} and \texttt{ArtifactUpdate} now always encode \texttt{"contextId" => event.context\_id || ""}.
    \item \textbf{Content-Type 415 Strictness}: HTTP-based endpoints strictly enforce \texttt{Content-Type: application/json} or \texttt{application/a2a+json}, responding with HTTP 415 Unsupported Media Type on deviations.
\end{enumerate}

\section{BEAM Process Supervision and Isolation}
To guarantee that a failure in one agent invocation cannot corrupt sibling tasks, \texttt{ash\_a2a} isolates execution across three supervision tiers:
\begin{enumerate}
    \item \textbf{Transport Supervisor}: Manages Bandit HTTP server listeners, GRPC server adapters, and socket acceptors.
    \item \textbf{Task Supervisor}: Dynamically spawns ephemeral workers for each message dispatch. Crashing workers emit \texttt{\{:DOWN, ref, :process, pid, reason\}} intercepted by the parent agent GenServer, mapping crashes to typed \texttt{TASK\_STATE\_FAILED} transitions without taking down the node.
    \item \textbf{Registry Event Bus}: Non-blocking in-memory pub/sub routing task events between worker processes and SSE/gRPC streaming connection pumps.
\end{enumerate}

\section{Multi-Shard Durable EKV Storage}
State durability is provided by \texttt{EKV}, an embedded key-value store utilizing 8 parallel shards and write-ahead logging (WAL). Under high concurrency and high file-descriptor pressures (POSIX \texttt{ulimit}), \texttt{ash\_a2a} implements batch descriptor recycling and WAL checkpointer pooling to eliminate \texttt{"unable to open database file"} failures.

\section{Continuous Identity Attestation with SPIFFE mTLS}
Every agent instance binds to a SPIFFE Workload API Unix Domain Socket, continuously streaming X.509 SVID credentials:
\[
\mathrm{SVID}_{\mathrm{agent}} = \langle \mathrm{spiffe://domain/agent/id}, K_{\mathrm{pub}}, \mathrm{CertChain} \rangle
\]
Mutual TLS (mTLS) handshake validation occurs at the Bandit connection plug level, rejecting callers whose trust bundles fail cryptographic verification.

\section{Monotonic AuthZEN Authorization}
Fine-grained authorization decisions are delegated to OpenFGA / AuthZEN Policy Decision Points (PDP). To prevent privilege escalation in delegated workflows, every downstream delegation must prove monotonic narrowing:
\[
\forall c \in C_{\mathrm{delegated}}: \quad c \in C_{\mathrm{initiator}} \implies \text{Monotonicity Holds}
\]

\section{Post-Quantum Attestation: ML-DSA-65 WASM Affidavits}
To guarantee forward-secure tamper-evidence against quantum computing adversaries, execution receipts are signed via ML-DSA-65 (FIPS 204 post-quantum digital signature algorithm) executed inside a deterministic WebAssembly runtime (\texttt{ash\_affidavit}). The resulting hash chain forms an append-only cryptographic ledger.
