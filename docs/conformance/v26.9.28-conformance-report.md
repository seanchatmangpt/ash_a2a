## Red team result

Verdict: FAIL. Defects confirmed by executed DB-free scripts in a scratch directory. No repo
file was edited. Status per defect is open.

- B1: one approval yields a certificate for any audience (approval does not bind audience).
- T4: a revocation written after the actuator loads its context but before the store
  dequeues is ignored (stale-context race, shown in-process).
- T2: truncating `journal.jsonl` and restarting performs the same certificate twice
  (2 ledger entries for one digest).
- T3: truncating `effect_ledger.jsonl` is undetected; replay returns evidence for a missing
  entry. Chains are unkeyed and unanchored.
- B2: truncating the authority issuance journal allows re-issue and approval replay.
- B3: approval tier is chosen from requester-supplied effect bytes (amount 1 in payment
  class needed no approval).
- Vacuous court paths: key-material scan omits the Fleet handle and keymaster ops; the
  oracle authorizes by effect digest only, not by certificate.
- Coverage gap: no catalog attack for truncation, journal-versus-ledger cross-check,
  stale-context revocation, cross-audience issuance or requester-declared amount tier.
- Minor: `quorum_default` 1 when config omits it; socket chmod after listen; no connection
  cap on UDS/TLS listeners.
